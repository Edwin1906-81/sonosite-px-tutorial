Key PX controls in one place
  • 2D, C, M, D: imaging modes. Press D once to show the D-line, press D again (or UPDATE) to start the Doppler sweep. M works the same way.
  • Doppler Mode on the touch panel picks PW, CW or TDI (CW and TDI only in cardiac exam types).
  • Touchpad moves the D-line, gate, color box, zoom box and calipers. SELECT switches calipers or moves to the next step of a measurement. UPDATE finishes an action, starts or stops the sweep, and switches focus between the 2D image and the sweep.
  • Freeze (snowflake) freezes and unfreezes. When frozen the GAIN wheel scrolls the cine buffer.
  • CALCS opens the analysis packages and saves measurements to the report. CALIPER gives quick measurements that are saved only on the image.
  • Save image (camera) saves the image and the measurements to the report. Save clip saves a cine clip during live imaging.
  • In the Focused Cardiac exam the pages are named Left Heart, Right Heart, Volume Status and Great Vessels instead of the full cardiac package pages.
Button sequences follow the Sonosite PX User Guide (P21894-09C). Labels can differ by software version and exam type. Values are teaching examples; thresholds follow ASE guidance. pulmonarypocus.com
